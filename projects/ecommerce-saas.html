Multi-Vendor E-Commerce SaaS Platform

Multi-Tenant Full Stack Marketplace Engine

E-Commercial SaaS is a modular multi-vendor marketplace platform designed to separate administrative platform governance, seller vendor onboarding with KYC verification, dynamic inventory management, and buyer checkout workflows.

Problem Statement

Standard single-seller online stores cannot scale to support multi-vendor market operations. Building a SaaS MVP requires strict role-based access control (RBAC), multi-tenant user table isolation, vendor KYC submission pipelines, dynamic catalog management, and cart transaction handling without cross-tenant data leaks.

Proposed Architecture & Solution

The system divides responsibilities into dedicated modules (/buyer, /seller, /shared):

  • Super Admin Module: Platform maintenance, vendor onboarding validation, user table governance, and global transaction logging.
  • Seller Vendor Module: Merchant registration UI, credential hashing, KYC submission API, product catalog CRUD, and inventory tracking.
  • Buyer Module: Public product storefront browsing, session-based cart management, and order placement pipeline.

Key Technical Accomplishments

  • Role-Based Access Control (RBAC): Engineered session-driven authorization isolating Super Admin privileges from Merchant Sellers and Public Buyers.
  • Relational Database Design: Designed MySQL tables linking users, vendor profiles, product inventory SKUs, and buyer order transactions.
  • Vendor KYC Pipeline: Implemented structured signup endpoints storing vendor credentials safely and managing verification statuses.
