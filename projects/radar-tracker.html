ASTERIX CAT240 Radar Data Processor & Tracker

Real-Time Telemetry Processing & Target Kinematics Estimator

This project implements a system designed to decode, parse, filter, and track raw radar target coordinates generated in **EUROCONTROL ASTERIX CAT240** format, visualising smoothed targets on a simulated Plan Position Indicator (PPI) sweep.

Problem Statement

Raw radar sensors generate analog scans filled with thermal clutter, atmospheric noise, and signal reflections. Attempting to parse binary packets in real-time while maintaining target tracks causes severe CPU choke points. Without statistical filtering, displaying raw coordinates results in erratic target jumping and false track pings.

The Data Processing Pipeline

The system processes raw inputs sequentially across isolated modules to ensure low telemetry latency:

ASTERIX Binary Stream ➔ Parser Engine ➔ CFAR Noise Filter ➔ Spatial Clustering ➔ Kalman Tracker ➔ PPI Visualizer

Kalman Filtering Mathematics

To smooth measurement errors, we implement a **linear 2D Kalman Filter** modeling kinematic states: position ($p_x, p_y$) and velocity ($v_x, v_y$).

// State Vector:
X = [p_x, p_y, v_x, v_y]^T

// Prediction Step:
X_pred = F * X_prev
P_pred = F * P_prev * F^T + Q

// Measurement Update:
K = P_pred * H^T * (H * P_pred * H^T + R)^-1
X_est = X_pred + K * (Z - H * X_pred)
P_est = (I - K * H) * P_pred

Where F represents the state transition model, P is the state estimation covariance, Q models process covariance (acceleration noise), R represents measurement noise covariance (sensor uncertainty), and Z is the actual measured target position vector.

Challenges & Solutions

  • ASTERIX Bit-Oriented Decoding: Decoupling coordinate bytes from binary bit fields is CPU intensive. Solved by implementing dynamic lookup schemas and byte offsets pre-compiling.
  • Target Identity Crossings: When two targets pass closely, the tracker can swap their identities. Solved by implementing the Hungarian Algorithm on Euclidean distance cost matrices.
  • OpenCV rendering lag: Generating high-resolution radar circles on video streams causes memory leaks. Resolved by rendering to a double-buffered matrix canvas and drawing vectors asynchronously.
